## 3. Explicit Summary of Architectural Decisions for Approval

The following specific architectural decisions are submitted for formal reviewer approval before M01 code generation:

1. **Technology Baseline:** Ratification of Java 21, Spring Boot 4.0.9, Spring AI 2.0.2, springdoc 3.0.x, Keycloak 26.x, PostgreSQL 16, and Redis 7, with unresolved dependency compilation designated as M01 Spike 1.
2. **Outage Architecture & Audit Durability:** Ratification of the local WAL buffer (`var/audit-fallback/audit-deferred.wal`) with post-outage continuous reconciliation for low-risk calls ($\le 5\text{ min}$), and immediate fail-closed behavior for medium/high-risk calls or audit buffer failures.
3. **Redis & Kill-Switch Fail-Closed Semantics:** Ratification that write operations fail closed if Redis is down, development in-memory counters are barred from production, and pre-dispatch checks abort execution if an entity was killed.
4. **Approval State Machine:** Ratification of the 7-state approval model, argument re-validation on edit, configurable timeouts, and JSON-RPC error responses.
5. **Identity Anti-Spoofing & RBAC:** Ratification of signed `X-User-Assertion` JWTs for end-user context, Keycloak `ROLE_ADMIN` and `ROLE_APPROVER`, and form CSRF protection.
